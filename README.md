# Europa en Ruta

Guía web para el viaje por capitales europeas (junio–julio 2026).

## Ciudades incluidas

1. **Barcelona** — 21 jun
2. **París** — 22–24 jun
3. **Londres** — 24–26 jun
4. **Bruselas** — 26–27 jun
5. **Ámsterdam** — 27–28 jun
6. **Frankfurt** — 28–29 jun
7. **Venecia** — 29 jun – 1 jul
8. **Roma** — desde 1 jul

## Cómo ver el sitio

Abre `index.html` en tu navegador, o sirve la carpeta con un servidor local:

```bash
# Python
python -m http.server 8080

# Node (si tienes npx)
npx serve .
```

Luego visita `http://localhost:8080`.

## Estructura

- `index.html` — página principal
- `css/styles.css` — estilos
- `js/data.js` — datos de ciudades y lugares
- `js/app.js` — interactividad (modal, filtros, menú)

No requiere instalación de dependencias.
